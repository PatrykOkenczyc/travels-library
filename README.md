# TravelsLibrary
 
All your travel in one place.
 
TravelsLibrary is a web and mobile app for keeping everything about a trip together: bookings, tickets, documents, photos and notes. The idea is simple: instead of digging through emails, screenshots and cloud folders before a flight, you open one app and it's all there.
 
The project is in early development. The backend foundation and user authentication are done, the rest of the features are planned.
 
## Planned features
 
- Trips as the main entity (dates, places)
- Flights, hotels and tickets attached to a trip
- Documents, with OCR to pull data out of scanned tickets
- Photos with pins on a map
- Notes
- Budget per trip
- Travel history
- Offline access on mobile
